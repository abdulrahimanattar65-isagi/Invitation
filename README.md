# Wedding Invitation (React + Vite)

## Run
    npm install
    npm run dev        # open the URL shown (best viewed in phone-size window)
    npm run build      # outputs /dist — upload anywhere (Netlify, Vercel, GitHub Pages)

## Change dates, names, venue, timings
Open **src/config.js**. Change `dateISO` (e.g. "2027-03-20T17:00:00") — the displayed day,
date, time and live countdown all update automatically. Edit names, venue, timeline, dress code, RSVP there too.

## Change colours
`src/styles.css` → `:root` variables (--emerald, --gold, --ivory).
